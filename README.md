# Linux Cheatsheet

Интерактивная шпаргалка по базовым командам Linux: управление файлами, права доступа, система и процессы, сеть.

**Демо:** https://asyx-creator.github.io/

## Возможности

- Живой поиск с плавным скрытием неподходящих команд и карточек
- Копирование команд в один клик
- Тёмная тема, адаптивная вёрстка
- Горячие клавиши: `/` — поиск, `Esc` — очистить
- Чистые HTML5, CSS3 и Vanilla JS, без внешних библиотек

## Запуск

```bash
git clone https://github.com/asyx-creator/linux-cheatsheet.git
cd linux-cheatsheet
python3 -m http.server 8000
```

Откройте http://localhost:8000 или просто `index.html` в браузере.
