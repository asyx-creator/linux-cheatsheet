Linux Cheatsheet

Базовые команды терминала — копируйте в один клик.

/

01

Управление файлами

  • ls -la

    Список файлов, включая скрытые, с подробностями

  • cd /path/to/dir

    Перейти в указанную директорию (cd ~ — домой)

  • mkdir -p new/dir

    Создать директорию вместе с родительскими

  • rm -r folder

    Удалить директорию рекурсивно. Осторожно: без корзины

  • cp -r src dest

    Скопировать файл или директорию

  • mv old.txt new.txt

    Переместить или переименовать файл

02

Права доступа

  • chmod 755 script.sh

    rwx для владельца, r-x для группы и остальных

  • chmod +x script.sh

    Сделать файл исполняемым

  • chmod -R 644 dir/

    Рекурсивно выставить rw-r--r--

  • chown user:group file

    Сменить владельца и группу файла

  • sudo chown -R user dir/

    Рекурсивно сменить владельца директории

03

Система и процессы

  • top

    Процессы и нагрузка в реальном времени (выход — q)

  • ps aux

    Все запущенные процессы всех пользователей

  • ps aux | grep nginx

    Найти процесс по имени

  • kill 1234

    Корректно завершить процесс по PID (SIGTERM)

  • kill -9 1234

    Принудительно завершить процесс (SIGKILL)

  • df -h

    Свободное место на дисках в удобном формате

  • free -h

    Использование оперативной памяти и swap

04

Сеть

  • ping -c 4 google.com

    Проверить доступность хоста (4 пакета)

  • curl -I https://example.com

    Получить только HTTP-заголовки ответа

  • curl -O https://example.com/file.zip

    Скачать файл с сохранением исходного имени

  • ip a

    Сетевые интерфейсы и их IP-адреса
